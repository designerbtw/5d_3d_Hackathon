# Сценарии демонстрации

## Основной (3 минуты)
1. Открыть чат, показать подключение к LLM.
2. Запрос: «Кронштейн под нагрузку, PETG, без поддержек» + STL.
3. Показать по ходу: карточки вызовов (режим, материал, рецепт, настройки), отклонённые значения, таблицу вариантов ориентации, прогресс слайсинга.
4. Итог: время, расход материала, файлы 3MF и G-code, объяснение решений.

## Смена материала
«Перенастрой на ABS»: агент меняет материал, температуры и адгезию, напоминает о особенностях материала, повторно нарезает.

## 5D
Показать выбор режима для детали с вращательной симметрией и объяснение, почему выбран cylindrical.

## Как получить результаты для сдачи
Для каждой модели: новый диалог, приложить файл, вставить описание задачи из выдачи, дождаться экспорта. Файлы появятся в папке результатов (настройка в чате), скриншоты сохранить как `chat_1.png`, `chat_2.png` и т. д. Положить в `results/<имя_модели>/`.
